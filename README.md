# Crun-Classic
Crun:C

A simple code runner for Android.

Crun:C (Commandsrun) is a project where you can write, test, and run code in different programming languages.

Supported languages

- Python
- Java
- JavaScript
- C
- C++
- Lua
- Ruby
- Go
- Rust

Features

- Code editor
- Run code
- Terminal output
- Standard input
- Multiple programming languages
- Dark theme inspired by GitHub

Platform

Android

Status

Work in progress.

Execution

Uses a Piston-compatible server to execute code.
